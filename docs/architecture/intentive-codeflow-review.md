# Intentive codeflow: second review receipt

Reviewed **2026-09-29**: all **23 areas** of [intentive-codeflow.mmd](intentive-codeflow.mmd). The comparison starts from diagram baseline `ca1ba412`; source was inspected at code HEAD `ed00649c`. The reviewed working diagram contains **365 boxes and 830 edges**, compared with **307 boxes and 684 edges** before this pass.

The boxes represent responsibilities of different sizes. They support reasoning about requirements and their dependencies, but their count is neither a module count nor a claim that 100% of the code is represented. This review followed existing boxes into inputs, callers, defaults, admission checks, outputs, persistence, consumers, failure, retry and cancellation paths. It added missing decisions and corrected relationships that could mislead a deletion discussion.

Four reviewers covered separate scopes, with rotated ownership for the second pass and peer review of material findings. Production source and focused existing tests were inspected. This is source evidence; it does not establish physical Mac behavior, audible voice acceptance, provider behavior, deployed configuration, remote delivery or release readiness. No product behavior was changed by the diagram review.

Important limits now visible in the diagram:

- **Pi `capture_screen` delivery:** Swift writes WebP paths; [Node wraps the result as JSON text](../../desktop/macos/agent/src/runtime/relay-tool-result.ts#L37); [the owned Pi extension scans raw PNG/JPEG path lines](../../desktop/macos/pi-mono-extension/index.ts#L284). The normal producer/consumer contract therefore does not match. The map records this source gap; the review did not repair it or test a live provider.
- **Task semantic coverage:** [`backfillIfNeeded`](../../desktop/macos/Desktop/Sources/ProactiveAssistants/Services/EmbeddingService.swift#L297) exists, but no production caller was found in the reviewed tree. An existing index is not evidence that every task has a vector.
- **Recovery is incomplete:** [database salvage](../../desktop/macos/Desktop/Sources/Rewind/Core/RewindDatabase.swift#L767) can retain only screenshot metadata or create a fresh database. [Video rebuilding](../../desktop/macos/Desktop/Sources/Rewind/Services/RewindIndexer.swift#L1059) reconstructs frames/time without original app, window, OCR or device provenance. Neither path guarantees recovery of all shared product data.
- **Export and deletion have explicit scopes:** [local export](../../desktop/macos/Desktop/Sources/Account/Export/LocalUserDataExport.swift#L351) exports selected structured data, caps Focus at 500 and excludes Rewind media/OCR, raw databases and secrets. [Server export](../../backend/services/users/data_export.py#L38) is account metadata. [Account wiping](../../backend/database/users.py#L751) recursively removes `users/uid`, while separate deletion receipts, top-level billing records and shared caches are other authorities.
- **Unknown reachability remains unknown:** retained APIs, configured stubs and dormant delivery/backfill helpers are labelled separately. A caller not found during source inspection is not proof that removing the code has no effect.

The diagram scope remains active macOS, the owned local Node/Pi integration, registered canonical backend behavior and the map viewer. Paused Windows, dependency internals, credentials/private state, build outputs and full build/release/test workflows are excluded; represented release APIs do not expand that scope into operational qualification.
