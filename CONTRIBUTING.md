# Contributing to Intentive

Read the [product constraints](openwiki/INSTRUCTIONS.md#product-constraints) and
[engineering rules and Definition of Done](openwiki/INSTRUCTIONS.md#engineering-rules).
The [development guide](openwiki/codebase/operations/development.md) and
[testing guide](openwiki/codebase/testing/contracts.md) explain the local workflow.

Trace the behavior to its owner and tests; include the native OpenWiki update
with code changes. Large or ambiguous features begin as an issue. Maintainers
land through reviewed PRs; agents publish only when explicitly instructed.
