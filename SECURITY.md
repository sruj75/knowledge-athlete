# Security

Report vulnerabilities privately. Do not post exploit details in public issues
or pull requests. Use this repository's Security tab if private reporting is
available; otherwise ask the maintainers for a private channel first.

The [preserved security policy](openwiki/INSTRUCTIONS.md#security-policy) describes
report contents, safe research, and coordinated disclosure. Its inherited Omi
scope and upstream reporting address are provenance, not an Intentive release
or support commitment. [Open identity and legal obligations](openwiki/INSTRUCTIONS.md#identity-and-legal-handoff)
record the remaining owner decisions.
